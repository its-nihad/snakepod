# SnakePod

SnakePod is a classic Snake game built with plain HTML, CSS, and JavaScript. Guide the snake around the board to eat berries and grow longer without hitting the walls or your own tail. You can play with the arrow keys or WASD on a computer, or use the on-screen buttons on a phone. Your best score is saved in the browser, and the game gets faster as you play.

The snake is drawn on a canvas with a shaded, scaly body, eyes, and a flicking tongue, so it looks much closer to a real snake than the usual blocks. The game also has a pause button, a live score display, and a bright, clean design that fits both desktop and mobile screens. Everything is contained in a single HTML file with no frameworks, which makes it easy to open, edit, and host.

Click this link to play the game: [https://its-nihad.github.io/snakepod/](https://its-nihad.github.io/snakepod/)
